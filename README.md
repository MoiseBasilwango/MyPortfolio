# Moïse Basilwango — Personal Portfolio

A modern, responsive personal portfolio showcasing my work, technical skills, projects, and journey as a Full-Stack Developer and Product Builder.

Inspired by Apple's minimalist design philosophy, the portfolio focuses on clean typography, intuitive navigation, generous whitespace, and a refined user experience.

## Overview

This portfolio serves as my personal space on the web, where I present my background, development skills, featured projects, and ways to connect with me.

Built with HTML, CSS, and JavaScript, it features a responsive layout optimized for desktop, tablet, and mobile devices.

## Features

- Apple-inspired design: Minimalist interface with clean typography, subtle colours, and elegant spacing.
- Responsive layout: Adapts to desktop, tablet, and mobile screens.
- Hero section: Introduction and navigation to featured projects.
- About section: Personal background, interests, and professional focus.
- Skills section: Overview of programming languages, frameworks, databases, and development tools.
- Featured projects: Dedicated presentations for MERIDIAN and ORBIT.
- GitHub integration: Automatically retrieves up to six recent public, non-fork repositories using the GitHub REST API.
- Contact section: Email contact, social links, and copy-email functionality.
- Smooth navigation: Smooth scrolling, mobile navigation, and a back-to-top button.
- Accessibility: Keyboard focus indicators and reduced-motion support.

## Technologies Used

- Structure: HTML5
- Styling: CSS3
- Functionality: JavaScript
- API Integration: GitHub REST API
- Version Control: Git and GitHub

## Getting Started

Follow these steps to run the portfolio locally.

### 1. Clone the repository

git clone https://github.com/MoiseBasilwango/portfolio.git

### 2. Navigate to the project directory

cd portfolio

### 3. Open the project

Open index.html directly in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

portfolio/
|
|-- index.html

## GitHub Integration

The portfolio uses the GitHub REST API to retrieve public repository information.

API endpoint:
https://api.github.com/users/MoiseBasilwango/repos?sort=updated&per_page=6

The repository section displays:
- Repository name
- Description
- Primary programming language
- Stars
- Forks

An internet connection is required for this feature.
